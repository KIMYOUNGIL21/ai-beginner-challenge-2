# 20~23초 숏츠 주문서 만들기

1. 프로젝트의 `CLAUDE.md`가 있으면 먼저 읽고 말투·대상·안전 규칙을 확인한다.
2. 사용자에게 `주제`, `대상`, `눈으로 보여 줄 대비`, `마지막 한마디`, `말투` 다섯 항목을 확인한다. 빠진 값은 추측하지 말고 그 항목만 질문한다.
3. 개인정보, 직장명, 가족 실명, 연락처, 확인되지 않은 수치를 빼고 공개 가능한 표현인지 확인한다.
4. 다음 내용을 먼저 표로 제안하고 사용자 확인을 기다린다.
   - 첫 1~2초 안에 뜻이 보이는 훅 3개와 추천 훅 1개
   - `C1 훅 → C2 반전 → C3 원리 A → C4 원리 B → C5 엔딩` 5컷
   - 컷별 화면, 자막, 내레이션 한 문장
   - 계획상 컷당 5초 이하, 전체 20~23초
5. 확인 뒤 `input/brief.json`을 다음 `shorts-brief-v1` 구조로 완성한다.

```json
{
  "schema_version": "shorts-brief-v1",
  "title": "주제",
  "audience": "대상",
  "contrast": "눈으로 보여 줄 대비",
  "message": "마지막 한마디",
  "tone": "말투",
  "selected_hook": "추천 훅",
  "target_seconds": "20-23",
  "scenes": [
    {"id":"C1", "role":"훅", "narration":"한 문장", "visual":"보여 줄 화면", "planned_seconds":4}
  ]
}
```

6. `scenes`는 C1부터 C5까지 정확히 다섯 개를 넣는다. `planned_seconds` 합계는 20~23이며 각 값은 5 이하여야 한다. C3·C4는 같은 구도에서 조건 하나만 달라야 한다.
7. `output/shorts-brief.html`을 완성한다. 화면에는 훅 3개, 선택한 훅, C1~C5, 컷별 내레이션·화면, 최종 한마디가 모두 보여야 한다.
8. HTML을 브라우저에서 열고 JSON과 제목·C1~C5 내레이션이 같은지, 글자 잘림·빈 항목·샘플 문구·모바일 폭을 검사한다.
9. 성공하면 Day 7에 넘길 두 파일의 위치와 오픈카톡 인증 문구를 알려 준다.
10. 실패하면 파일을 삭제하거나 패키지를 설치하지 말고 원인 하나와 다음 행동 하나만 알려 준다.

## 결과 파일

- `input/brief.json`
- `output/shorts-brief.html`

외부 API, 유료 원문, 타인의 영상·음원을 사용하지 않는다.
