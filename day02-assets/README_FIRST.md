# Day 2 시작 자료

오늘 Projects에 넣을 파일은 `my-profile.txt` **한 개뿐**입니다.

1. `my-profile.txt`를 열고 `[ ]` 안의 네 곳을 내 말로 바꿉니다.
2. Claude Desktop에서 **프로젝트 → 새 프로젝트**를 누릅니다.
3. 프로젝트 지식의 `+`를 눌러 `my-profile.txt`를 넣습니다.
4. 교재의 문장을 보내 콘텐츠 주제 3개와 Day 3에서 쓸 ★ 주제의 `복사용 5칸`을 받습니다.

전화번호, 이메일, 주소, API 키, 실제 고객 이름은 적지 않습니다.
