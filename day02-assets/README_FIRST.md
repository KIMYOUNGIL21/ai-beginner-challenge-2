# Day 2 시작 자료

오늘 프로젝트의 **컨텍스트**에 넣을 파일은 `my-profile.txt` **한 개뿐**입니다.

1. `my-profile.txt`를 열고 콜론 오른쪽 네 값만 바꿉니다. 값 양쪽 `[`와 `]`는 지우고 섹션 제목은 그대로 둡니다.
2. Claude Desktop에서 **프로젝트 → 새 프로젝트**를 누르고 `닉네임` 대신 실제 카톡 이름을 씁니다.
3. 프로젝트 홈 오른쪽 **컨텍스트의 + (파일 추가)**를 눌러 `my-profile.txt`를 넣습니다. 작은 메뉴가 보일 때만 `파일 추가`를 한 번 더 누릅니다.
4. 프로젝트 홈 중앙의 **Claude에게 프롬프트를 입력하세요** 입력칸에 교재 문장을 보냅니다. `메시지를 입력하세요...`로 보여도 같은 곳입니다.
5. 두 번째 채팅은 위쪽 프로젝트 이름을 다시 눌러 홈으로 돌아온 뒤 중앙 입력칸에서 시작합니다.
6. 첫 결과로 돌아갈 때는 위쪽 프로젝트 이름 → 프로젝트 홈 → **최근 항목**에서 첫 대화를 누릅니다.
7. 콘텐츠 주제 3개와 Day 3에서 쓸 ★ 주제의 `복사용 5칸`을 받습니다.
8. 결과가 길면 글자를 작게 줄이지 말고 PNG 두 장으로 나눕니다.

전화번호, 이메일, 주소, API 키, 실제 고객 이름은 적지 않습니다.
