# Day 2 시작 자료

오늘은 `project-packs`에서 연습용 자료 네 개를 골라 **프로젝트 컨텍스트**에 넣습니다.

1. 압축을 풀면 생기는 `day02-assets` 폴더 안에서 시작합니다.
2. 기본 추천은 `project-packs/home`입니다. 다른 사례를 원하면 `career`를 고릅니다.
3. Claude Desktop에서 **프로젝트 → 새 프로젝트**를 누릅니다.
4. 선택 폴더의 `01`부터 `04`까지 파일 네 개를 컨텍스트에 넣습니다.
5. 실행서의 프로젝트 지침을 붙여넣고 저장합니다.
6. 새 채팅을 열어도 대상과 한 줄 약속을 기억하는지 시험합니다.
7. 탭 3개가 작동하는 LIFE BRAND 운영본부를 만듭니다. **여기까지가 오늘의 필수입니다.**
8. 가장 멋진 화면 1장을 캡처해 오픈카톡에 인증합니다.
9. `templates/my-brand-brief.txt`에 Day 3용 브리프 7칸을 옮겨 적고 `D02_닉네임_Day3브리프.txt`로 저장합니다.
10. (선택) 내 자료로 바꿔 볼 때는 네 파일을 복사해 `my-brand` 폴더에 넣고 고친 뒤 **새 프로젝트**에 넣습니다.
    제공 사례와 내 자료를 한 프로젝트에 섞지 않습니다. 새 프로젝트는 앞 대화를 모르므로
    실행서 7단계의 긴 프롬프트를 통째로 다시 붙여넣어야 합니다.

전화번호, 이메일, 주소, API 키, 실제 고객 이름, 회사 기밀은 적지 않습니다.
