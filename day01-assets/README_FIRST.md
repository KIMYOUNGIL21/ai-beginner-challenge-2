# Day 1 시작 자료

1. 이 폴더 안의 `input` 폴더를 엽니다.
2. `creator-performance.csv` 파일이 보이면 준비 완료입니다.
3. Claude Desktop에서 `홈 → 새로 생성 → 채팅`을 엽니다.
4. 입력칸 옆 `+`를 눌러 `creator-performance.csv`를 첨부합니다.
5. Day 1 실행서의 **작품 1 — Creator Pulse** 프롬프트를 복사해 보냅니다.

`creator-performance.csv`는 육아·생활 기록자와 은퇴를 준비하는 50대의 가상 콘텐츠 성과 데이터입니다. 실제 개인정보는 들어 있지 않습니다.

파일 이름을 바꾸거나 Excel에서 다시 저장하지 말고 그대로 첨부하는 것이 가장 쉽습니다.
