# 여기서 시작하세요

1. 이 폴더를 Claude Desktop의 **Code → 로컬 → 폴더 선택…**에서 엽니다.
2. 화면 아래의 `자동` 또는 현재 모드 이름을 눌러 **수동**으로 바꿉니다.
3. Claude에게 `이 폴더를 읽고 쇼츠 만들 준비가 됐는지 확인해 주세요.`라고 보냅니다.
4. 준비가 끝나면 `demo-project`로 API 없는 연습 MP4를 먼저 만듭니다.

Day 6을 완주했다면 `day06-handoff` 안에 본인의 `brief.json`과 `shorts-brief.html`을 넣습니다. Claude가 `import_day6_brief.py`로 C1~C5를 검사해 `my-short/script.txt`로 가져오므로 대본을 다시 입력하지 않습니다. Day 6을 건너뛰었다면 그대로 두고 새 주제부터 시작합니다.

Flow 실습 직전에는 `flow-board.html`을 브라우저에서 크게 엽니다. 한옥 처마 견본의 C1~C5 프롬프트를 복사하고 완료 체크를 눌러 0/5에서 5/5로 바뀌는 방법을 연습합니다. 견본 문장은 자기 주제에 그대로 사용하지 않습니다.

처음부터 기술 명령을 입력하지 마세요. Mac은 `PRECHECK_MAC.md`, Windows는 `PRECHECK_WINDOWS.md`를 Claude가 읽고 한 단계씩 안내하게 합니다. Python·FFmpeg가 없다면 수강생 혼자 설치하지 말고 운영자와 `INSTALL_CLINIC.md`를 진행합니다.

실제 내 쇼츠에는 Typecast와 Google Flow 계정 상태가 필요합니다. API 키는 Claude 채팅에 붙여넣지 않습니다. 전체 순서는 [온라인 Day 7 전체 실행서](https://kimyoungil21.github.io/ai-beginner-challenge-2/#day7), Typecast 키 연결은 `TYPECAST_SETUP.html`, Flow 화면은 `FLOW_5CUT_GUIDE.html`을 봅니다. 최종 파일명은 `D07_닉네임_쇼츠.mp4`입니다.
