# 씬 프롬프트 공식

## 프롬프트 문법

한 씬 프롬프트는 항상 이 순서로 쓴다. 순서를 지키면 Flow가 앞쪽을 내용으로,
뒤쪽을 스타일로 읽는다.

```
[장면 묘사] → [카메라 무빙] → 실사풍 시네마틱 다큐멘터리 →
[색조] → [렌즈/심도] → 은은한 필름 그레인 →
한글이나 한국어 문자는 넣지 않는다.
```

- **장면 묘사** — 명사와 동사로. 형용사는 색조 칸에서 처리한다.
- **카메라 무빙** — 반드시 한 문장으로 명시한다. 빠뜨리면 정지컷이 나온다.
- **색조** — 전반부와 후반부를 의도적으로 반대로 잡는다. 이게 전환을 만든다.
- **금지어 문장** — 매 씬 끝에 붙인다. 화면 속 글자는 자막과 충돌한다.

## 연쇄 컷

한 씬 안에서 동작을 여러 단계로 이어 붙일 때는 `먼저 … 이어서 … 그 다음 …
마지막으로 …` 로 쓰고, 끝에 **"카메라는 끊김 없이 하나의 연속 동작으로
움직인다"** 를 넣는다. 이게 없으면 Flow가 컷을 나눠버린다.

## Flow 결과와 사용 길이

현재 Flow에는 별도 길이 선택이 없고 확인한 기본 결과는 약 8초다. 화면이 바뀌면
실제 결과 길이를 따른다. 결과가 사용 길이보다 충분히 길면 뒤를 버리고, 짧으면
해당 컷만 다시 생성한다. `scenes.json`에는 사용 길이만 적는다.

| 표기 | 뜻 |
|---|---|
| `4.2초 사용` | 결과 영상에서 앞 4.2초 사용 |
| `연쇄 4단` | 한 컷 안에 동작 4단계 |

## 씬 배치 — 6컷 기본

**첫 영상은 6컷으로 잡는다.** 11컷이면 Flow 대기만 30분이 넘어가고,
첫 편에서 그건 완주를 막는다. 6컷이면 뼈대는 그대로 살면서 생성 총량이
약 48초로 줄어든다.

| 씬 | 역할 | 색조 |
|---|---|---|
| C1 | 훅 · 문제 단언 | 차가운 톤 |
| C2 | 흔한 해결책이 실패한다 | 차가운 톤 유지 |
| C3 | **★전환★** 색조 반전 | 따뜻한 톤으로 |
| C4 | **★핵심★** 메커니즘 A | 따뜻한 톤 |
| C5 | **★핵심★** 메커니즘 B — A와 대비 | 따뜻한 톤 |
| C6 | 대구 엔딩 | 따뜻한 톤 |

C4와 C5를 **같은 구도에서 조건 하나만 바꾸는 쌍둥이 컷**으로 잡는 게
이 배치의 핵심이다. 대비가 메커니즘을 설명한다.

## 늘리려면

익숙해진 뒤 11컷으로 늘릴 때는 새 아이디어를 넣는 게 아니라 **기존 컷을
쪼갠다.**

- C2 → 해결책마다 한 컷씩 (블라인드 / 코팅 / 두꺼운 유리)
- C4·C5 → 연쇄 단계를 별도 컷으로 분리
- C6 앞에 **완전 정지컷**을 하나 넣어 대구 A/B를 만든다 — 앞이 계속
  움직였기 때문에 정지 자체가 리듬이 되고 마지막 무빙이 살아난다

# 예시 — 한옥 처마

## 대본

여름에 통유리 건물 안은 40도까지 오릅니다.
블라인드를 치면 낮에도 불을 켜야 합니다.
우리는 빛을 막을 방법만 찾았습니다.

그런데 한옥은, 애초에 막을 생각이 없었습니다.

한여름 태양은 머리 위 75도. 처마가 그 빛을 잘라냅니다.
한겨울엔 30도까지 내려앉아, 같은 처마 아래로 방 안까지 들어옵니다.

우리는 사철 같은 집을 원했고, 한옥은 사철 다른 집을 지었습니다.

## 씬 프롬프트

### C1 · 4.2초 사용
현대 통유리 오피스 빌딩 외벽을 아래에서 올려다본 초저각. 한여름 백색 태양이 유리면에 정면으로 꽂혀 반사광이 화면을 태우듯 하얗게 번진다. 카메라가 유리면을 따라 위로 빠르게 솟구치고, 그 순간 유리 안쪽에서 아지랑이 같은 열기가 일렁인다. 실사풍 시네마틱 다큐멘터리, 과다 노출된 차가운 백색광과 창백한 청회색 톤, 광각 렌즈, 강한 렌즈 플레어, 은은한 필름 그레인. 한글이나 한국어 문자는 넣지 않는다.

### C2 · 6.1초 사용 · 연쇄 2단
통유리 사무실 내부. 먼저 회색 블라인드가 위에서 아래로 촤르륵 내려와 창을 덮고 실내가 순식간에 어두워진다. 이어서 천장 형광등이 하나씩 탁탁 켜지며 창백한 인공광이 책상 위를 덮고, 창밖 햇빛은 완전히 사라진다. 카메라는 창가에서 실내 안쪽으로 천천히 물러난다. 사람은 나오지 않는다. 실사풍 시네마틱 다큐멘터리, 차갑고 채도 낮은 청회색 톤에 형광등의 녹빛, 35mm 렌즈, 얕은 심도, 은은한 필름 그레인. 한글이나 한국어 문자는 넣지 않는다.

### C3 · 3.8초 사용 ★전환★
황금빛 아침 햇살이 쏟아지는 한옥 마당. 카메라가 마당 흙바닥 높이에서 대청을 향해 초고속으로 돌진하며 기와지붕의 깊은 처마 그늘 아래를 통과하고, 그 끝에 활짝 열린 대청마루와 그 너머 안쪽 방까지 이어지는 빛의 길이 드러난다. 처마 끝 기와의 곡선이 역광에 검은 실루엣으로 스치고 먼지가 금빛으로 반짝이며 강한 렌즈 플레어가 터진다. 실사풍 시네마틱 다큐멘터리, 강렬하게 따뜻한 금빛과 나무 갈색 톤, 극단적 명암 대비, 광각 렌즈, 은은한 필름 그레인. 한글이나 한국어 문자는 넣지 않는다.

### C4 · 6.8초 사용 ★★핵심 · 연쇄 4단★★
한옥 한 칸을 옆에서 자른 건축 단면도. 처마, 마루, 방 안쪽이 한눈에 보인다. 먼저 화면 위쪽 높은 곳에서 굵은 금빛 광선 다발이 가파른 각도로 내리꽂히고 태양 고도를 나타내는 붉은 각도호가 그어진다. 이어서 그 광선이 처마 끝에 정확히 잘려 나가며 마루 앞턱에서 멈추고, 방 안쪽은 서늘한 그늘 속에 남는다. 그 다음 카메라가 그늘진 방 안으로 밀고 들어가 어둠과 바깥 빛의 경계를 지난다. 마지막으로 카메라가 방 안에서 멈춰 정적인 화면이 된다. 카메라는 끊김 없이 하나의 연속 동작으로 움직인다. 실사풍 건축 시각화, 따뜻한 금빛 광선과 나무 갈색, 붉은 주석선만 강조, 광각 렌즈, 은은한 필름 그레인. 한글이나 한국어 문자는 넣지 않는다.

### C5 · 6.2초 사용 ★★핵심 · 연쇄 4단★★
앞과 완전히 동일한 한옥 단면도, 동일한 카메라 위치. 먼저 금빛 광선 다발이 이번에는 훨씬 낮고 비스듬한 각도로 들어오고 붉은 각도호가 앞보다 눈에 띄게 작게 그어진다. 이어서 그 광선이 처마 끝을 스치듯 통과해 마루를 건너 방 안쪽 깊숙이까지 뻗어 들어가고 방바닥 끝 벽면에 밝은 빛 웅덩이가 맺힌다. 그 다음 카메라가 그 빛을 따라 방 안으로 함께 밀고 들어간다. 마지막으로 빛으로 가득 찬 방 안에서 카메라가 멈춰 정적인 화면이 된다. 카메라는 끊김 없이 하나의 연속 동작으로 움직인다. 실사풍 건축 시각화, 낮게 깔린 겨울 금빛과 따뜻한 나무 갈색, 붉은 주석선만 강조, 광각 렌즈, 은은한 필름 그레인. 한글이나 한국어 문자는 넣지 않는다.

### C6 · 4.8초 사용 · 대구 엔딩
아침 황금빛 햇살을 받은 한옥의 정면. 기와지붕의 깊은 처마가 완만한 곡선을 그리며 좌우로 뻗어 있고 그 아래 나무 기둥과 창호지 문이 줄지어 서 있다. 카메라가 마당 흙바닥 높이에서 처마를 향해 천천히 밀고 들어가 그늘진 마루를 통과하고, 안쪽 어둠 너머로 방 안의 빛이 어렴풋이 드러난다. 나무 기둥 표면의 오래된 결과 마모가 선명하다. 실사풍 시네마틱 다큐멘터리, 따뜻한 금빛과 나무 갈색 톤, 깊은 그림자, 강한 역광과 렌즈 플레어, 35mm 아나모픽 렌즈, 은은한 필름 그레인. 한글이나 한국어 문자는 넣지 않는다.

합성해 측정한 낭독 길이는 **31.95초**다. 컷 경계를 문장 시작점에 맞춘 값:

```json

 {
  "file": "clips/c04.mp4",
  "use": 6.8
 },
 {

  "use": 6.2
 },
 {
  "file": "clips/c06.mp4",
  "use": 4.8

```

현재 기준 생성 총량 약 48초. 사용 합계 31.9초로 내레이션과 맞는다.

## 씬 길이는 낭독 뒤에 정한다

**대본을 눈으로 읽고 씬 길이를 추정하지 말 것.** 처음 이 예시의 씬 길이를
감으로 잡았을 때 합계가 45초였는데, 실제 낭독은 그보다 30% 가까이 길었다.

순서는 이렇다.

1. 대본을 쓴다
2. `tts.py`를 먼저 돌린다 → `words.json`
3. 문장 시작 시각을 보고 컷 경계를 정한다
4. 그 값으로 `scenes.json`을 쓰고 Flow에서 생성한다

컷을 문장 **중간**이 아니라 **시작점**에 맞추면 화면 전환과 말이 함께
떨어져서 훨씬 자연스럽다. 다음 명령으로 문장 시작 시각을 볼 수 있다.

```bash
python3 -c "
import json
w=json.load(open('work/words.json')); seen=set()
for x in w:
    if x['sentence'] not in seen:
        seen.add(x['sentence']); print(f\"{x['start']:6.2f}s  {x['text']}\")"
```
