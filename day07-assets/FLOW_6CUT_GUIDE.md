# Google Flow — 6컷 받기

## 시작 전

- Chromium 계열 데스크톱 브라우저를 권장합니다.
- 현재 계정의 Flow 이용 가능 여부와 크레딧을 확인합니다.
- `prompts.md`에 C1~C6과 각 **사용 길이**가 있어야 합니다.

## 처음 한 번만 하는 설정

1. `https://labs.google/fx/ko/tools/flow`를 엽니다.
2. 첫 방문 화면이면 **Create with Google Flow**를 누르고 로그인합니다.
3. 대시보드에서 **+ 새 프로젝트**를 누릅니다.

![Google Flow 대시보드의 새 프로젝트 버튼](screenshots/02-flow-new-project.png)

4. 새 프로젝트 아래쪽의 프롬프트 입력칸을 찾습니다.
5. 입력칸 왼쪽 아래의 모델명·화면비율·개수가 적힌 **설정 단추**를 누릅니다.
6. **동영상 → 9:16 → x1** 순서로 누릅니다.
7. 현재 모델과 크레딧 차감을 직접 읽고 설정창을 닫습니다.

![동영상, 9:16, x1을 고른 설정 화면](screenshots/03-flow-video-9x16-x1.png)

`x1`은 결과를 한 개만 만든다는 뜻입니다. 첫 연습의 크레딧 사용을 줄이기 위한 설정입니다.

## C1부터 C6까지 반복하는 순서

1. `prompts.md`에서 해당 C카드의 프롬프트 전체를 복사합니다.
2. **무엇을 만들고 싶으신가요?** 칸에 붙여넣습니다.
3. 오른쪽 **만들기**를 누릅니다.
4. 결과를 처음부터 끝까지 재생합니다.
5. 주제와 맞고 이상한 문자가 없으며 움직임이 무너지지 않은 결과 하나를 고릅니다.
6. 위쪽 **다운로드**를 누르고 파일명을 바꾸지 않습니다.
7. 진행표에서 해당 컷의 다운로드 칸을 체크합니다.

![결과 화면의 다운로드 아이콘](screenshots/04-flow-result-download.png)

위 그림에서 왼쪽부터 세 번째, 아래로 향한 화살표 아이콘이 다운로드입니다.

현재 확인한 화면에는 길이 선택칸이 없었고 약 8초짜리 결과가 만들어졌습니다. 최종 조립에서 카드의 **사용 길이**만큼 앞부분을 잘라 씁니다. Flow 화면이 바뀌어 길이 선택칸이 보이면 사용 길이보다 긴 값을 고릅니다.

## 다시 만들 기준

- 화면에 알아보기 어려운 문자나 로고가 생김
- 사람 얼굴·손·물체가 무너짐
- 프롬프트의 핵심 행동이 보이지 않음
- 장면이 필요한 길이보다 짧음
- 앞뒤 장면의 인물·공간·색이 심하게 달라짐

실패한 컷만 다시 만듭니다. 성공한 다섯 컷을 다시 만들 필요는 없습니다.
