# Google Flow — 세로 영상 5개 받기

## 이 화면에서 하는 일

Claude가 만든 `prompts.md`의 C1~C5 주문문을 Flow에 넣고, 세로 영상 다섯 개를 다운로드합니다. **영상 생성만 사람이 하고, 파일 정리와 최종 조립은 Claude가 합니다.**

## 시작 전에 확인

- `my-short/prompts.md`에 C1~C5가 있다.
- Flow 로그인과 현재 크레딧을 확인했다.
- 결제나 생성 전에 화면의 실제 차감 숫자를 읽는다.
- 현재 화면의 한 번 차감 숫자에 5를 곱해 다섯 컷의 필요량을 확인한다. 숫자는 모델·계정·시점에 따라 달라질 수 있다.

## 처음 한 번만 설정

1. [Google Flow](https://labs.google/fx/ko/tools/flow)를 Chrome 또는 Edge에서 엽니다.
2. 처음이면 **Create with Google Flow**를 누르고 로그인합니다.
3. 대시보드의 **+ 새 프로젝트**를 누릅니다.

![새 프로젝트 버튼](screenshots/02-flow-new-project.png)

4. 왼쪽 메뉴에서 **모든 미디어**를 고릅니다.
5. 화면 아래 입력칸 오른쪽의 회색 설정 단추를 누릅니다.
6. 아래 표대로 고릅니다.

| 항목 | 선택 | 확인 이유 |
|---|---|---|
| 종류 | **동영상** | 정지 이미지가 아니라 영상 생성 |
| 방식 | **애셋** | 텍스트 주문문으로 새 영상 생성 |
| 화면비 | **9:16** | 쇼츠용 세로 화면 |
| 모델 | **Omni Flash** | 원본 파이프라인 검증 모델 |
| 길이 | **6s** | 컷당 최대 5초를 쓰고 끝 1초를 버림 |
| 개수 | **x1** | 한 번에 하나만 생성해 크레딧 보호 |

![9:16과 x1 설정](screenshots/03-flow-video-9x16-x1.png)

설정 패널 아래의 **생성 시 사용 크레딧**을 읽고 그 숫자에 5를 곱합니다. 남은 양보다 크거나 차감 방식이 이해되지 않으면 **만들기를 누르지 않고** 모델·길이·개수와 현재 표시를 Claude와 운영자에게 보여 줍니다.

## C1~C5 생성

긴 문장을 직접 긁어 복사하지 말고 Claude에게 요청합니다.

```text
C1 프롬프트만 클립보드에 복사해 주세요. 전문은 채팅에 다시 출력하지 마세요.
```

1. Flow 입력칸에 붙여넣습니다.
2. 설정 단추에 `동영상 · 9:16 · 6s · x1`이 보이는지 다시 봅니다.
3. **만들기**를 누릅니다.
4. C2, C3, C4, C5도 같은 방식으로 바로 생성에 걸어 둡니다.
5. 완성본을 처음부터 끝까지 재생합니다.
6. 이상한 글자, 무너진 사람·물체, 멈춘 카메라가 없는지 확인합니다.
7. 다운로드 단추를 눌러 **한 개씩** 받습니다. 파일명은 바꾸지 않습니다.

![다운로드 단추](screenshots/04-flow-result-download.png)

## 꼭 지킬 한 가지

생성은 다섯 개를 연달아 걸어도 되지만, **다운로드는 완성되는 순서대로 한 개씩** 합니다. 여러 개를 동시에 받으면 저장 시각이 같아져 C1~C5 순서를 자동으로 찾기 어렵습니다.

이미 한꺼번에 받았다면 삭제하거나 이름을 바꾸지 말고 Claude에게 말합니다.

```text
Flow 영상을 한꺼번에 다운로드했어요. 순서를 추측하지 말고 확인 시트를 열어 주세요.
```

## 크레딧이 끝났다면

성공한 컷을 다시 만들지 않습니다. 받은 영상만으로 완성하도록 요청합니다.

```text
크레딧이 끝났어요. 지금 받은 클립만으로 문장 경계와 자막 시간은 유지하며 완성해 주세요.
```
