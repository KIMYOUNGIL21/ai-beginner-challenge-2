DAY 7 · TYPECAST 연결

Typecast 키 연결 — 4단계면 끝

Typecast는 문장을 목소리로 바꿔 주는 서비스입니다. 열쇠(API 키) 하나를 발급받아 파일에 붙여넣으면 연결이 끝납니다.

1

Typecast 로그인

Typecast에 접속해 로그인하세요. 계정이 없으면 가입부터 하면 됩니다.

2

API 키 복사

Typecast 개발자 페이지로 들어가 API 키를 만들고 복사를 누르세요.

3

파일에 붙여넣기

day07-start 폴더 안의 typecast-key.txt를 두 번 눌러 여세요. 빈 파일이 열리면 복사한 키를 붙여넣으세요.

4

저장하고 닫기

Windows는 Ctrl+S, Mac은 Cmd+S로 저장하고 창을 닫으면 끝입니다. 조립 도구가 이 파일에서 키를 알아서 읽습니다.

지킬 것 하나

키는 내 계정의 열쇠입니다. 채팅·카카오톡·인증 캡처에 올리지 마세요. 실수로 올렸다면 개발자 페이지에서 그 키를 지우고 새로 만들어 다시 붙여넣으면 됩니다.

키 발급 화면이 이 설명과 다르게 보이면 개강 당일 운영자 안내를 따르세요.
