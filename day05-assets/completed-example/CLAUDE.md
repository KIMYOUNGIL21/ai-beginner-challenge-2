# 오늘의 15분 작전실 작업 규칙

## 대상과 목표

- 육아와 집안일 사이에 내 일을 자꾸 미루는 사람이 사용한다.
- 막막한 일을 지금 시작할 수 있는 세 단계로 나눈다.

## 말투와 화면

- 짧고 다정한 한국어를 쓴다.
- 모바일에서 입력칸과 버튼을 크게 유지한다.
- 코발트블루와 살구색을 사용하고 글자 대비를 유지한다.
- 결과는 `준비 → 집중 → 마무리` 세 단계로 보여 준다.

## 기능

- 할 일, 사용 가능 시간, 현재 에너지를 입력받는다.
- `작전 만들기`를 누르면 입력을 반영한 세 단계가 나온다.
- 단계 완료 버튼을 누를 때마다 진행률이 0%에서 100%까지 바뀐다.
- 빈 입력에는 쉬운 안내를 보여 준다.

## 안전

- 개인정보, API 키, 확인하지 않은 사실을 넣지 않는다.
- 외부 설치와 인터넷 연결 없이 `index.html` 하나로 작동하게 한다.
- 기존 파일을 삭제하지 않고 변경 전에 계획을 먼저 보여 준다.
