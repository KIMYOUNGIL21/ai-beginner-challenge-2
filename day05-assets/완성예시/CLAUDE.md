# 이 프로젝트의 작업 규칙

## 도구와 사용자

- 도구 이름: 오늘의 첫 행동
- 사용할 사람: 할 일이 많아 시작을 미루는 사람
- 해결할 문제: 오늘 할 일의 가장 작은 첫 행동을 바로 시작하게 돕는다.

## 말투 규칙

- 짧고 쉬운 한국어로 쓴다.
- 사용자를 탓하거나 과장하지 않는다.
- 한 번에 행동 하나만 안내한다.

## 화면 규칙

- 휴대폰에서 제목, 입력칸, 버튼을 크게 보이게 한다.
- 글자와 배경의 대비를 충분히 유지한다.
- 버튼이 화면 밖으로 나가지 않게 한다.

## 안전 규칙

- 개인정보와 API 키를 파일이나 화면에 넣지 않는다.
- 확인되지 않은 사실과 성과를 만들지 않는다.
- 기존 `index.html`을 삭제하지 않는다.
- 파일을 바꾸기 전에 변경 계획을 먼저 보여 준다.
